# Murmur Client

The Murmur frontend is a React application built with Vite.

## Commands

- `npm run dev` starts the development server.
- `npm run lint` runs ESLint.
- `npm run build` creates the production bundle in `dist`.

Set `VITE_API_URL` in the build environment to the API origin. Vite embeds this public URL in the client bundle; do not put secrets in `VITE_*` variables.
